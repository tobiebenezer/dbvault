# Phase 8H: All-White Theme

DBVault now uses a white application shell across desktop and mobile.

- White sidebar and mobile drawer
- White top bar
- White page background
- White cards, panels, menus, alerts, toasts, logs, and setup surfaces
- Subtle neutral borders provide separation
- Emerald is reserved for primary actions, active navigation, and positive status
- Amber and red remain semantic warning and danger indicators only
- All card surfaces remain `rounded-md` or greater
